# SDK change log              {#sdk_change_log}

# 2020/06/09
* Add "make provision-run-qemu" and "make provision-run-device" commands to debug provision APP

# 2020/05/22
* Add header, library and example of openssl(1.1.1).

# 2020/03/16
* Add Secure Time API to nbl_fwk, and add example about it.

# 2020/01/15
* ${SDK_HOME}/examples/sd.privilege is used as the security domain privilege (maximum privilege) configuration file by default.
* Added the feature to update security domain privileges for OTrP provision and debug.

# 2019/12/26
* Delete the create_key.sh script in the SDK. This script calls several key generation scripts. It is difficult to find the error location when the script runs error. Therefore, it is recommended to manually call the corresponding script to generate the secret key.
* Added introduction of export_key.sh script in SDK.

# 2019/12/25
* After the key is generated by OTrP key_store_tool, the injected key needed for the image will be exported under the export_key folder.

# 2019/12/11
* Add "delete-sd", "delete-qemu-sd" and "delete-device-sd" to making target for TA/HA program/far/tui.

# 2019/10/29
* The ree/include/nbl_fwk_ree/secmgr.h in sdk will no longer provide the nbl_otrp_close_device function.
  Secmgr will always support the provisioning/offline mode to install HA. Therefore, the close provision feature is no longer provided.

# 2019/10/18
* Implement privilege of Security Domain.

# 2019/10/14
* Add nfc_demo_ta to SDK example.
* Add attestation API libs to SDK.

# 2019/09/15
* Add libsec_conn_ree and libsec_conn_tee to SDK sample.
* Add openssl ree libs to SDK.

# 2019/09/06
* Change vncviewer to ssvncviewer for supporting vnc window scaling feature.
  TuiApp with 1080p or higher resolution can be auto-fitting into vnc window
  according to scaling factor, and user can interact with UI without scrolling.

# 2019/08/14
* Secure manager add the feature to delete SD for the “make provision” command.

# 2019/08/09
* Merge documents of doxygen and markdown document in SDK into one document with HTML format,
    taking place of SDK folder "SDK/docs".

# 2019/07/25
* Added Nebula TUI documentation.

# 2019/07/19
* Change default value of "enable_deprecated_syscalls" to false, before it's true.
  So all HA using deprecated trusty API such as "port_create" should be changed to new API name such as "_trusty_port_create",
  Or add "enable_deprecated_syscalls=true" in Makefile. Example is "examples/hee/trusty-api/Makefile".

# 2019/07/16
* Add keymaster header files for kmsetkey ta.

# 2019/07/15
* Can generate multiple versions of the provision ha data.

# 0.09
* Add OTrP certificate and key generation tools and documentation.
* Modify the HAID format in the document.
* Add OTrP the feature to generate provision debug data from provision data.

# 0.09 (2019/01/08)
* Implement run a HA with arguments, by adding "RUN_ARG" in Makefile or
  run command "RUN_ARG=XXX make run/run-qemu/run-device/". Example is "hee/libc".
* Modify the signature tool. The signature tool supports parsing of the manifest configuration file. Signing tool generates encrypted HA json data.
* Add provision feature.
* Add license.h in nbl_fwk_ree, and add example about it in "examples/nbl_fwk/license".
* Fix "make run/run-qemu/run-device" cannot transfer parameters for HA with SPACE.

# 0.08 (2018/12/13)
* Add examples "storage-mng" and "storage-mng2" to SDK/examples/hee.
* When "run-qemu" and "run-device" will pick differnet uuid by different HA's target name.
* Add HA signature tool.
* Nebula framework v0.01 release.

# 0.07 (2018/11/13)
* Change config option TRUSTY_APP_CONFIG_MAX_HEAP_SIZE to NBL_APP_CONFIG_MAX_HEAP_SIZE.
* Add secure manager debugging Tools. It is in the directory "sdk/run/otrp/debug_tool".
* Add option "-a" (disable ASLR) for run/run-qemu.sh.

# 0.06 (2018/10/23)
* Add the "-z max-page-size=4096" in the linker options on compiling HA. (make/hee-common.mk)
  It will reduce the size of page size in elf from 64K to 4K, so it will reduce the size of HA elf greatly.
* Add secure manager sdk tool.It can run a ha on the device.

# 0.05 (2018/09/21)
* Change the arguments of run-qemu.sh.
    * rename "-a" of command "run-qemu.sh", because "disable ALSR" causes the memory problem.
    * Add argument "-r" of command "run-qemu.sh", it will start the NEBULA system on "release" build.
      The "release" build is for releasing, so remove all tests and debug tools.
    * Remove "start qemu with gdb and freeze CPU for continue", add this feature as "-s" argument of "run-qemu.sh".
* Change grt_fwk to nbl_fwk.
* Set HA default heap size to 5MB.
* Add TRUSTY_APP_CONFIG_MAX_HEAP_SIZE config option to HA manifest.
* Add CA/HA communication sample.

# 0.04 (2018/08/27)
* Change the script in sdk/make/*, make it sense to make mutiple tasks simultaneously.<br>
    Users don't need to change the Makfile, but users can add option "-j" for "make".<br>
    And target "all" in sdk/examples/Makefile is added the option "-j".
